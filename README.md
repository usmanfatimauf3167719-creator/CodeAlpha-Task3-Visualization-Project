## Project Overview

This project presents a comprehensive visualization and analysis of sales data to uncover meaningful patterns, trends, and business insights.

Using Python, Pandas, and Matplotlib, the project transforms cleaned sales data into clear and informative visualizations. The analysis focuses on sales performance across products, regions, customer segments, shipping methods, and time periods.

---

## Project Objectives

The primary objectives of this project are to:

- Analyze overall sales performance.
- Identify high-performing product categories and sub-categories.
- Compare sales performance across regions.
- Analyze sales by customer segment.
- Identify the top-performing products.
- Examine sales by shipping mode.
- Analyze monthly sales trends.
- Compare annual sales performance.
- Understand the distribution of sales values.
- Generate meaningful business insights.

---

## Dataset

The project uses a cleaned sales dataset containing information about orders, products, customers, regions, sales, shipping methods, and dates.

### Dataset File

`Data_Visualization_Cleaned.csv`

---

## Data Preparation

The following preparation steps were performed:

1. Loaded the cleaned sales dataset using Pandas.
2. Converted `Order Date` and `Ship Date` into datetime format.
3. Extracted year, month, and month name from the order date.
4. Grouped sales data according to relevant business dimensions.
5. Aggregated sales values for visualization.
6. Prepared summarized datasets for individual charts.
